# 23. SESSION CHECK

Before protected actions:

```text
if AuthenticationManager.isSessionUnlocked():
    continue
else:
    authenticate()
```

Example:

```text
Future<void> uploadDocument() async {

    if (!authManager.isSessionUnlocked()) {
        final success = await authManager.authenticate();

        if (!success) {
            return;
        }
    }

    // NOW open file picker

    final file = await pickFile();

    if (file == null) {
        return;
    }

    await secureVault.store(file);
}
```

IMPORTANT:

Authentication must happen BEFORE opening the picker, not after the picker starts.

हाँ भाई, अब requirement बिल्कुल clear है: **100% local-first**, sensitive documents/JSON/images cloud पर नहीं जाएँगे, और AI footprint **20–25 MB target** रहेगा ताकि 2 GB RAM वाले Android phones पर भी practical रहे।

एक correction: **पूरे app का APK/IPA 20–25 MB रखना** और **AI model को 20–25 MB रखना** अलग चीजें हैं। अगर तुम्हारा मतलब *AI model* 20–25 MB है, तो नीचे वाला architecture सही है। पूरे app को 20–25 MB में रखना अलग optimization project होगा।

# 1. CORE REQUIREMENT

This entire AI/document-processing system must be LOCAL-FIRST.

Sensitive user data must remain on the user's device by default.

The system must NOT require a cloud server for:

- OCR
- Aadhaar document processing
- PAN document processing
- JSON generation
- Profile storage
- Document storage
- Document parsing
- Field mapping
- Smart Fill decision making
- Local form analysis where platform APIs permit it

The application must remain functional without an internet connection for all local features.

Internet should NOT be required merely to read or process a document.

The AI model package must target:

MINIMUM:
20 MB class

MAXIMUM:
25 MB

DO NOT bundle a large LLM.

DO NOT silently download model files in the background.

The production AI model package must stay within the defined 20–25 MB budget.

Measure:

- raw model size
- compressed model size
- final packaged size
- runtime memory
- RAM usage

Do not confuse model size with complete APK/IPA size.
